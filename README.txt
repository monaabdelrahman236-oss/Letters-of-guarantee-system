منصة متابعة التواريخ — HTML + CSS + JavaScript

الملفات:
- index.html: هيكل الصفحة
- style.css: التنسيق والتصميم
- script.js: إضافة السجلات والبحث والتصفية والتنبيهات والاستيراد

طريقة التشغيل:
1. فكّي ضغط الملف ZIP.
2. افتحي المجلد في VS Code عبر File > Open Folder.
3. افتحي index.html في المتصفح (كليك يمين > Open with > Chrome)، أو استخدمي إضافة Live Server إن كانت مثبتة.
4. لا تحتاج هذه النسخة إلى React أو npm.

ملاحظات:
- البيانات تحفظ في localStorage داخل المتصفح على نفس الجهاز.
- الاستيراد يدعم CSV فقط؛ احفظي ملف Excel بصيغة CSV UTF-8 أولًا.
- التنبيه يظهر داخل الموقع عند فتحه؛ لا توجد إشعارات خارجية عند إغلاق الموقع.
